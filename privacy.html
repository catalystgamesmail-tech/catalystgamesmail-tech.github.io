Privacy Policy

Last updated: November 15, 2026

About this application

Story Video Bot is a personal Windows application operated by catalystgamesmail-tech for their own YouTube channel. This policy describes the application and its informational website.

Google permissions

The application requests these permissions:

  • https://www.googleapis.com/auth/youtube.readonly — to retrieve channel identity information and confirm the intended upload destination.
  • https://www.googleapis.com/auth/youtube.upload — to upload videos and associated metadata, including optional future publication times.

Google handles sign-in and consent in the browser. The application does not request or store the Google account password. Authorization tokens let it operate later without repeating sign-in while authorization remains valid.

Information stored on the computer

The application stores channel identifiers and names, authorization tokens, video metadata, publishing times, upload identifiers and status, local file paths, file hashes, settings, receipts, and recovery records on the operator's computer.

Generated stories, narration, captions, videos, history, and operational logs are also stored locally.

Authorization tokens and resumable upload addresses are encrypted using Windows DPAPI for the current Windows account. Settings, upload journals, other records, and the downloaded OAuth client configuration are not encrypted by the application. The operator controls access to these files and the computer.

Sharing and other providers

Authorized videos and metadata are sent to Google/YouTube. Uploads start private. Enabled scheduling makes them public at the selected times. Google processes this information under the Google Privacy Policy.

The application has no data-selling, advertising-tracking, or model-training feature. It does not send Google account data to the local story or voice models. Setup may download model files from their providers, which receive ordinary download requests.

Website privacy

This website adds no JavaScript, cookies, analytics, or collection forms. GitHub Pages hosts it and may process visitor request information under the GitHub Privacy Statement.

Retention and disconnecting

There is no automatic account-data deletion feature. Local files remain under the operator's control.

To disconnect the application:

  1. Pause automatic uploads, disable the daily task, and stop the running application.
  2. Open Google Account connections and remove the application's access.
  3. Delete the application's local state/youtube/auth.dpapi file.

Revoking access or deleting local files does not delete uploaded videos or cancel scheduled publication. Manage those items in YouTube Studio.

Deleting other local information

To remove other local data permanently, first stop using the application and check any pending uploads in YouTube Studio. Then delete the desired local records and outputs.

Do not delete recovery journals merely to retry an uncertain upload; doing so can create duplicates.
